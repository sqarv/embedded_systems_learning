#### Learning Embedded Systems ✏️
A collection of small projects focused on learning electronics, microcontrollers, and firmware development.

#### 📁 Projects
* **[01-Parking-Sensor](./01_arduino_parking_sensor)** - Distance sensing with ultrasonic signals and buzzers.
* **[02-IR-LED-Control](./02_ir_led_control)** - Remote control logic with PWM and step-acceleration.
* **[03-Simon-Game](./03_simon_game)** - Memory game featuring an LCD screen, custom BJT transistor switching, and long-term EEPROM storage.
* **[04-NTC0Thermometer](./04_ntc_thermometer)** - Real-time temperature monitor using an NTC thermistor, LCD display, and the logarithmic Beta formula.
